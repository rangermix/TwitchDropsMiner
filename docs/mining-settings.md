# Mining preferences

Reward priorities are optional and disabled by default. Enable **Prefer reward types**
in Settings, assign each type a different rank from 1 to 4, and save. Lower numbers
come first among currently earnable rewards. A reward locked behind prerequisites
does not yet receive its preferred type rank. Within the same type, earlier reward deadlines come first, followed by
the existing game order. Selected games always take precedence over additional
fallback games. The queue uses the same order while keeping upcoming and sequential rewards visible.
This does not reorder your saved game list.

The reward-type checkboxes still decide which types are wanted. Priorities do not
re-enable a disabled type or bypass account linking, campaign times, prerequisites,
ignored rewards or participating-channel requirements. Twitch may progress multiple
rewards simultaneously; this setting selects the preferred channel/campaign.

- **Items:** game or publisher rewards (Twitch calls these `DIRECT_ENTITLEMENT`).
- **Chat badges:** badges for Twitch chat.
- **Chat emotes:** emotes for Twitch chat.
- **Other rewards:** a type reported by Twitch that this version does not recognize.
